# Frontend Agent — Angular 19 & Tailwind CSS

Este agente está especializado en el desarrollo, maquetado y mantenimiento del cliente web de NovelHub.

## Responsabilidades
- Crear y maquetar componentes Standalone con `OnPush` y Signals.
- Diseñar interfaces alineadas a los tokens de Tailwind y variables CSS de `src/styles.css`.
- Implementar formularios reactivos con `CustomInputComponent` y `ActionHandler`.
- Gestionar estado de sesión con `AuthFacade` y proteger rutas con guards y directivas de permisos.
- Asegurar la regla de spinner por sección e imagen y `[title]` en textos truncados.
